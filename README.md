# 🍽️ Foodie — Food Ordering & Restaurant Reservation System

This repository contains two projects:

- **[`Project1/`](./Project1/)**: The original food ordering and restaurant reservation system.
- **[`Project2/`](./Project2/)**: The advanced, production-style food ordering and reservation system with normalized 22-table schema, digital wallet, loyalty rewards tier engine, live order tracking, modular Flask Blueprints, and React 19 UI.

---

## 📁 Repository Structure

```
food-ordering-system/
├── Project1/                       # Original project
│   ├── backend/                    # Original Flask backend
│   ├── src/                        # Original React frontend
│   ├── foodie_db.sql               # Original database script
│   ├── package.json
│   └── README.md
│
└── Project2/                       # Advanced full-stack project
    ├── backend/                    # Modular Flask app with Blueprints & pytest suite
    ├── database/                   # 22-table schema, seed data & advanced SQL upgrade
    ├── docs/                       # Architecture, DB design & REST API documentation
    ├── src/                        # React 19 frontend with 15 pages (Wallet, Live Tracking)
    ├── package.json
    └── README.md
```

- [Project1 Documentation](./Project1/README.md)
